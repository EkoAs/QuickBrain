Game Modes Guide

    Learn how to master all 7 challenges before you start!

    🧮

    Mode 1: Classic Math

    Solve random basic arithmetic equations (+, -, ×, ÷) before the timer runs out.

    ➕

    Mode 2: Addition

    Focus purely on addition. Find the correct sum of the numbers shown on screen.

    ➖

    Mode 3: Subtraction

    Test your speed in finding the correct difference between two numbers.

    ➗

    Mode 4: Division

    Find the accurate quotient. Only divisions with whole number results are given.

    🎯

    Mode 5: Target Pair

    You are given a target result (e.g., ? + ? = 8). Find the two correct numbers that make it true.

    ❓

    Mode 6: Middle Value

    Fill in the blank! Find the missing number in the middle of an equation (e.g., 5 + ? = 12).

    🧠

    Mode 7: Memory Grid

    Watch the tiles light up, remember their positions, and click them in the correct order. The grid expands as you level up!
